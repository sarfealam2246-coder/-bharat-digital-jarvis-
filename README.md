# Bharat Digital Jarvis

24×7 All-India 2-Agent Relay System + Skills-based Locked Demo Builder + Pure-White Foldable Android APK with Jarvis Hindi Voice.

## Quick Setup
1. Create a **Public** GitHub repository named `bharat-digital-jarvis`.
2. Enable **Settings → Pages → Deploy from a branch (`main` / `/docs`)**.
3. Upload `bharat-digital-jarvis-complete.zip` and add `.github/workflows/build-apk.yml`, `agent_1_relay.yml`, and `agent_2_relay.yml`.
4. Run **Actions → Build Bharat Digital Jarvis APK**, install `app-debug.apk`, open **Vault**, save your keys, and tap **Sync All 10 Keys to GitHub Secrets**.
